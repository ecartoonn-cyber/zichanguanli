# Personal Invest OS MVP 使用说明

## 打开本地模块化版本

在项目目录安装依赖并启动本地开发服务（需要 Node.js 与 pnpm）：`pnpm install`，再运行 `pnpm dev`，然后用浏览器打开本地地址。旧单文件原型保存在 `prototype/Personal-Invest-OS-MVP.html`，仅用于对照，不是当前模块化应用入口。

## 录入持仓

选择平台和产品类型，输入产品代码、当前金额、币种和平台显示的盈亏。按实际产品投资范围选择国内、海外或全球/混合；不确定时保留“待分类”。输入代码后点击“查询名称”，核对名称后保存。若查询不到，页面会给出失败原因和搜索入口；选“改为手工填写名称”后，持仓会显示“手工”标记。已有手工名称在再次查询失败时会保留。

盈亏建议填写“累计盈亏”口径和数据日期。当天盈亏不会用来计算持仓以来的收益率。填写累计盈亏金额时，收益率按“累计盈亏 ÷（当前持仓金额 − 累计盈亏）”估算；填写累计比例时，直接显示该比例。该计算是估算，不替代平台收益口径；分红、费用、部分赎回等会造成差异。若基数无法计算，系统不显示估算收益率。

## 看板与 Prompt

- 持仓卡片显示金额、盈亏口径、估算累计收益率、手工名称标记和金额/盈亏日期距今时间；相同平台和代码会在保存前提醒确认。
- 图表按产品类型、市场范围和币种分组，显示按已录入累计盈亏反推的估算组合收益率及数据覆盖数。正负收益以零线区分；不同币种分开；无累计盈亏的产品计入覆盖总数，但不参与收益率计算。
- 点击“生成 / 更新”查看诊断 Prompt。点击“确认并复制，去 ChatGPT 粘贴”后先确认数据，再复制到剪贴板；回到当前 ChatGPT 对话粘贴并发送。静态网页不能直接调用当前 ChatGPT 对话。
- 支持导出 JSON 备份和导入恢复。导入会替换本机当前数据，确认前会显示持仓数量及项目摘要；请定期备份。**本期不包含表格/批量持仓导入。**

## 查名失败的常见原因

当前按“产品类型”选用不同查询源，并要求查询结果代码与输入完全一致。基金代码若选成 A 股个股、证券代码若选成基金，或查询源无结果、超时、网络拦截，都会失败。银行理财和其他产品没有统一公开代码目录。代码与名称仍建议用发行方、基金公司、交易所/证券资料核对；无法核验时保留手工名称和待核验状态。页面无法读取之前查询源实际返回的数据，因此不能仅凭已保存的名称断定某个旧代码失败的唯一原因。

## 自动更新与隐私边界

默认数据存放在当前浏览器。用户登录并明确启用后，持仓和理财体检也会保存到个人火山 Supabase 账号，并按用户身份隔离；首次选择前不会上传或覆盖。应用仍不会自动读取支付宝、理财通、银行或券商，也不连接行情服务，当前没有开盘后/收盘后自动更新持仓收益。每日定时研究仍需要行情数据源与任务运行环境。可暂时在收盘后查看平台并更新金额、累计盈亏和日期，再生成 Prompt 让 ChatGPT 查公开市场资料。

查询名称时只会把产品代码发送给查询源，不发送金额或盈亏。不要录入账户密码、验证码或登录凭据。清理浏览器数据可能删除记录；共享设备请避免录入敏感信息。
